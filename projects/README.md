
# Учебные проекты и практические работы

В этом разделе представлены мои курсовые работы, лабораторные исследования и проекты, выполненные в ходе обучения по специальности «Информационная безопасность автоматизированных систем».

Основные направления:
- Защита приложений и данных
- Анализ сетевых угроз и уязвимостей
- Администрирование и защита операционных систем
- Программирование и работа с базами данных
- Низкоуровневое программирование
- Проектирование систем безопасности объектов ТЭК

Каждый проект содержит описание задачи, использованных технологий и результатов работы.
