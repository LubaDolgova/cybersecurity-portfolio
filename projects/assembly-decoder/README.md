
# Декодирование машинных кодов команд ассемблера

**Тип работы:** курсовая работа по низкоуровневому программированию.

## Цель
Разработка программы преобразования машинных кодов в инструкции ассемблера.

## Реализуемые команды
- BT
- RCL
- AAD

## Содержание
- Изучение структуры машинных инструкций.
- Анализ кодирования заданных команд.
- Разработка алгоритма декодирования.
- Реализация программы преобразования машинного кода в инструкции ассемблера.

## Приобретённые навыки
Понимание структуры машинных инструкций, принципов кодирования и декодирования, основ низкоуровневого программирования.
