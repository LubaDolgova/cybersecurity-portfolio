
# Защита данных в микросервисном приложении

**Тип работы:** курсовой проект.

## Цель
Разработка архитектурного паттерна защиты приложения от угрозы хищения обучающих данных.

## Выполненные задачи
- Анализ угроз и возможных сценариев хищения данных.
- Разработка архитектуры механизмов защиты.
- Реализация контроля доступа, мониторинга и аудита.
- Разработка и тестирование микросервисов.
- Моделирование подозрительной массовой выгрузки данных.
- Проверка фиксации событий безопасности и блокировки подозрительных запросов.

## Технологии
Docker Compose, PostgreSQL, Elasticsearch, микросервисная архитектура.

## Результат
Разработан и протестирован учебный механизм защиты данных, позволяющий выявлять подозрительную активность, фиксировать события аудита и блокировать подозрительные запросы.
