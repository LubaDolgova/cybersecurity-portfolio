
# Компьютерная игра «Куратор музея»

**Тип проекта:** учебный командный проект.

## Описание
Разработка компьютерной игры с использованием базы данных Oracle.

## Использованные технологии
- Oracle Database
- SQL
- PL/SQL
- Python

## Содержание проекта
- Проектирование структуры базы данных.
- Работа с таблицами и связями между ними.
- Использование SQL и PL/SQL для игровой логики.
- Взаимодействие программного приложения с базой данных.

## Результат
Разработан учебный игровой проект с использованием реляционной базы данных.
