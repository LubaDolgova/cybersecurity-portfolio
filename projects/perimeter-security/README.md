
# Проектирование системы охраны периметра объекта ТЭК

**Тип работы:** курсовая работа по специальной подготовке.

## Цель
Проектирование рубежей охраны периметра объекта топливно-энергетического комплекса с учётом модели нарушителя и потенциальных угроз.

## Выполненные задачи
- Анализ исходных характеристик объекта.
- Разработка модели нарушителя.
- Выбор инженерно-технических средств охраны.
- Проектирование рубежей охраны и размещения извещателей.
- Подготовка схем размещения оборудования.
- Расчёт стоимости предлагаемых решений.

## Результат
Разработан учебный проект инженерно-технической защиты объекта ТЭК с обоснованием выбора средств охраны и оценкой стоимости.
