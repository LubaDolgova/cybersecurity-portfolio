
# Научная деятельность

Автор и соавтор научных работ по информационной безопасности, сетевым технологиям и операционным системам.

## 1. Безопасность PXE Boot на Windows Server

Тема: «Настройка и функциональное тестирование PXE Boot на базе Windows Server. Вопросы безопасности».

Рассмотрены угрозы сетевой загрузки, уязвимости DHCP и TFTP, возможные атаки и меры защиты инфраструктуры.

[Страница статьи](https://uralolimp.website/prof/ru/article/view/54)

## 2. Защита RIPng от атак Route Injection

Тема: «Компенсирующие меры защиты протокола RIPng от атак типа Route Injection в условиях отсутствия встроенной аутентификации».

Проведено исследование уязвимостей динамической маршрутизации IPv6, моделирование атак и проверка защитных механизмов IPv6 ACL и ip6tables.

[Страница сборника](https://paradigma.science/n3-2026/)

## 3. Безопасность GNOME в Альт Linux

Тема: «Методы усиления безопасности графической среды GNOME в ОС Альт посредством механизмов блокировки Dconf».

Исследованы настройки безопасности GNOME, механизмы Dconf и возможные способы обхода ограничений.

[Сайт научного издания](https://paradigma.science/)

## 4. Тестирование производительности сетевого оборудования

Тема: «Исследование применимости PKTGEN для бенчмаркинга производительности сетевого оборудования в мультивендорной среде».

Работа опубликована в сборнике XII Международной научно-практической конференции «Современные исследования: перспективы и вызовы» (2026).
